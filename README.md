# 油品价格维护 · 多编辑人离线草稿台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

按油品保存目标价、生效时刻和修订说明的多编辑人离线草稿台，数据保存在浏览器 localStorage 中。

## 分层

- `src/data/`：类型、油品目录、字段定义与种子数据
- `src/rules/workbench.ts`：纯规则函数（整批校验、字段级 diff、冲突逐项确认、发布、撤回）
- `src/storage/localStore.ts`：localStorage 读写，整体状态单 key 原子写入
- `src/App.vue`：页面层，只负责渲染和交互编排

## 规则

- 同一油品已有草稿时，后保存者只登记字段级变更建议，原草稿不被覆盖
- 冲突按字段列出双方值，必须逐项选择后才能发布
- 发布后保留发布记录并清除对应草稿与冲突
- 批次内出现重复油品、非法时刻/价格、空编辑人或存储写入失败时整批撤回
- 刷新后草稿、冲突与发布历史均按油品恢复
