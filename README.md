# 油品价格维护（多编辑人离线草稿台）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（未新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- 按油品保存调价草稿：目标价、生效时刻、修订说明，同一油品同一时刻仅一份草稿。
- 同一油品已有草稿时，后保存者的提交自动转为**字段级变更建议**，不覆盖原草稿。
- 冲突逐字段列出"草稿值 / 建议值"供选择，**未逐项确认不得发布**。
- 发布后生成发布记录（含合并结果）并清除该油品草稿。
- 批次提交整批校验：批内油品重复、生效时刻非法（过去或不可解析）、存储写入失败，均**整批撤回**，不落库、内存状态回滚。
- 草稿、冲突裁决进度、发布历史均持久化在 localStorage，刷新后仍按油品对应。

## 分层

| 目录 | 职责 |
| --- | --- |
| `src/data/` | 领域类型（`types.ts`）与种子数据（`seed.ts`） |
| `src/rules/` | 纯函数业务规则（`draftRules.ts`）：批次校验、差异计算、逐字段裁决、发布判定与合并 |
| `src/storage/` | localStorage 读写与存档形状校验（`draftStorage.ts`），写失败抛错交由调用方回滚 |
| `src/components/` + `src/App.vue` | 页面：批次表单、草稿/冲突面板、发布历史，事务式落库（失败回滚内存状态） |
